# Backmatter Homebrew tap

```sh
brew install backmatter/tap/tex-ls
```

Prebuilt tex-ls for macOS and Linux, on Intel and ARM machines. No Rust compiler is
needed. Run `brew upgrade backmatter/tap/tex-ls` to upgrade.

See [editor setup](https://github.com/backmatter/tex-ls/blob/main/docs/guide/editor-setup.md).
